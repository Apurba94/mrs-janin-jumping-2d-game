# Mrs Janin — Build Memory

The project is being rebuilt from the previous 3D FPS into a standalone HTML, CSS, and JavaScript mobile runner. The implementation will favor a custom canvas game loop so it can be wrapped in Capacitor for Android without a runtime game-engine dependency. The Android deliverable will be a debug APK when the local SDK and Gradle prerequisites are available; signing a release APK is intentionally not attempted without user-owned signing credentials.
